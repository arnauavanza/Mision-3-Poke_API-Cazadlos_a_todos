#  Misión 3: Poke API

Este proyecto es una aplicación web moderna desarrollada con **Vue 3**, **Vite** y **TypeScript**. A continuación se detallan los pasos necesarios para configurar el entorno de desarrollo local tanto en **Windows** como en **Linux**.

---

##  Requisitos Previos

Antes de empezar, asegúrate de tener instalado **Node.js** en tu sistema (se recomienda la versión LTS más reciente).

* **Windows:** Descarga e instala el instalador oficial desde [nodejs.org](https://nodejs.org/).
* **Linux (Ubuntu/Debian):** Puedes instalarlo desde tu terminal ejecutando:
```bash
  sudo apt update
  sudo apt install nodejs npm

```

---

##  Configuración del Entorno

Sigue estos pasos en la terminal de tu sistema operativo (PowerShell/CMD en Windows o la Terminal nativa en Linux) para arrancar el proyecto:

### 1. Clonar el repositorio

Si aún no tienes el proyecto en local, clónalo usando HTTPS (método recomendado para evitar conflictos de permisos):

```bash
git clone (url ssh o https)

```

### 2. Entrar en la carpeta del proyecto

```bash
cd Mision-1-Hola-Vue

```

### 3. Instalar las dependencias

Este comando descargará todas las librerías necesarias (incluyendo Vue, Vite y TypeScript) en la carpeta `node_modules`:

```bash
npm install

```

### 4. Levantar el servidor de desarrollo

Enciende el entorno local para ver la aplicación en tu navegador:

```bash
npm run dev

```

Una vez ejecutado, la terminal te proporcionará un enlace local (normalmente `http://localhost:5173/`). Abre esa dirección en tu navegador para ver el proyecto en marcha.
